Workflows and setup

How do I send keyboard shortcuts with a MIDI controller on Windows?

Use the guide How to Send Keyboard Shortcuts with a MIDI Controller on Windows for a complete step-by-step setup.

Can I control Windows volume with a MIDI knob or fader?

Yes. You can map controls to system volume or target a specific app volume. See How to Control Windows Volume with a MIDI Controller.

Can I create one-button MIDI macros for apps?

Yes. You can chain shortcuts, delays, mouse actions, and program launches. See MIDI Controller Macros for Windows Apps.

Can I trigger audio samples from my MIDI controller on Windows?

Yes. With a licence, you can map sample triggers, stop buttons, and playback modes. See MIDI Audio Sample Playback on Windows.

Can I use a Behringer X-Touch One to control multiple volumes with one fader?

Yes. You can map different targets per preset and switch presets so one fader controls multiple volume targets. See the Behringer X-Touch One setup guide.

How do I set up a Behringer X-Touch One on Windows?

Use the Behringer X-Touch One Windows setup guide for connection, mapping, preset switching, and motorised fader feedback steps.

Licensing and installation

Can I use MIDI Command Studio without a licence?

Yes. Download MIDI Command Studio once and use it free with no time limit. A licence key unlocks all features. See Licence options for the limits.

Can I use more than one active device?

Without a licence, you can use one active device at a time. A licence unlocks multiple active devices.

Why does Windows show a warning when I run the installer?

Windows may show SmartScreen or security warnings for newer unsigned installers. See notes on the Download page.

Compatibility

Does it work with all MIDI controllers?

It works with most controllers that expose standard MIDI controls on Windows. Some devices may require specific mode settings.

Read the compatibility model and browse documented devices.

Support and documentation

Where do I get support?

Support is available in-app via Settings > Feedback so diagnostics can be included when needed. You can also use the website contact form for general questions, setup help, licensing issues, and bug reports.

Where is the full documentation?

Use the Help page for setup and detailed guides.
