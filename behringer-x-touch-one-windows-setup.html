X-Touch One Windows setup

Configure standard MIDI or Mackie/MCU operation, then set up preset switching, LED feedback, LCD labels, and motorised fader feedback in MIDI Command Studio.

Mode setup MIDI vs MCU MCS setup

Put the X-Touch One into MIDI or MC Std mode.

  1. 01
    Open mode selection

    Hold the STOP button and press the rotary knob.

  2. 02
    Choose the mode

    Use the rotary knob to select MIDI or MC Std.

  3. 03
    Finish

    Press the rotary knob multiple times until the LCD screen has no text.

MIDI mode and MCU mode behave differently.

Native in MCS

Standard MIDI mode

Buttons can be mapped normally and do not change controller channels. Use this when you want direct access to the hardware controls as ordinary mappings.

MCU in MCS

Mackie / MCU mode

The X-Touch One uses built-in channel strips CH1–CH8. Channel-select buttons are reserved for strip switching, while Mute, Solo, and Rec are linked to the selected strip.

MCU control behaviour

By switching channels on the controller, the fader, pan encoder, and Mute, Solo, and Rec buttons can each be mapped across eight channel slots in one preset. The Master button is reserved in MCU mode and switches the fader to the master channel; it is not mapped as a normal action button.

Make sure the hardware and app modes match: Native means standard MIDI mode; MCU means MCU standard.

Add the device, enable feedback, and create presets.

  1. 01
    Add the device

    Add the X-Touch One in MIDI Command Studio.

  2. 02
    Enable feedback

    Enable LED, motorised fader, and LCD preset feedback for the device in Settings.

  3. 03
    Create presets

    Create one or more presets for your workflows.

  4. 04
    Map preset switching

    Use Settings / Preset Switching so workflows can be changed without the mouse.

Create presets for different applications or tasks, then switch between them directly from the controller.

Supported feedback

MIDI Command Studio can control the X-Touch One's button LEDs, display preset names on its LCD, and move the motorised fader to the current mapped volume.
