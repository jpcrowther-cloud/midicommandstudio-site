Korg nanoKONTROL2 / MIDI Command Studio

Use the Korg nanoKONTROL2 as a Windows controller

The Korg nanoKONTROL2 can be used as a compact physical control surface for Windows, not just for DAW mixing. With MIDI Command Studio, its faders, knobs and buttons can control Windows volume, individual application volume, audio input levels, keyboard shortcuts, macros, media controls and other Windows actions.

Once the nanoKONTROL2 has been added to MIDI Command Studio, its controls can be learned directly and assigned to different functions.

Control Windows and application volume with the nanoKONTROL2

The eight faders and eight rotary knobs send MIDI CC values, making them well suited to Windows system and application volume control.

For example, separate faders can be assigned to the main Windows output and compatible applications such as a web browser, media player, communications app or other program with a Windows audio session.

MIDI Command Studio can also use compatible controls for Windows audio input volume and mute, allowing the nanoKONTROL2 to act as a small desktop audio controller for both playback and input devices.

Map nanoKONTROL2 buttons to Windows shortcuts and macros

The nanoKONTROL2's transport, Solo, Mute, Record and other buttons can be mapped to keyboard shortcuts, multi-step macros, media commands, application actions and MIDI Command Studio preset changes.

This means the controller can be used for workflows well beyond audio mixing, with buttons triggering commands in Windows applications while the faders and knobs handle continuous controls.

Use CC mode for MIDI Command Studio mappings

For general Windows control, CC mode is the most useful nanoKONTROL2 operating mode because its buttons, knobs and faders can be learned as standard MIDI Control Change messages.

Mappings can then be organised into MIDI Command Studio presets, allowing the same nanoKONTROL2 controls to perform different actions for different applications or workflows.

nanoKONTROL2 LED feedback

When the nanoKONTROL2's LED Mode is set to External, MIDI Command Studio can control supported button LEDs and update them to reflect mapped states.

This allows buttons such as mute or toggle controls to provide visual feedback.

nanoKONTROL2 drivers and Windows 11 MIDI Services

On Windows 11 24H2 or later, do not install the legacy KORG USB-MIDI Driver. Korg recommends uninstalling it if it is already installed and using the MIDI support provided by Windows MIDI Services instead.

The older KORG USB-MIDI Driver can conflict with Windows MIDI Services and may cause the nanoKONTROL2 or other Korg USB MIDI devices to disappear from MIDI applications or behave incorrectly.

See Korg's Windows MIDI Services notice and Microsoft's Windows MIDI Services known issues and workarounds if the nanoKONTROL2 is not appearing in MIDI Command Studio or another Windows application.
