Mackie Control Universal / MIDI Command Studio

Use Mackie Control (MCU) controllers with Windows

MIDI Command Studio can use Mackie Control Universal (MCU) controllers as general-purpose Windows control surfaces, rather than limiting them to DAW control.

Compatible Mackie/MCU hardware can be mapped to Windows system and application volume, keyboard shortcuts, macros, media commands, application actions and other Windows controls.

Depending on the controller, MIDI Command Studio can also use motorised faders, channel buttons, pan controls, mute, solo and record buttons, together with supported LED and display feedback.

Use a single-fader MCU controller for multiple Windows controls

On a single-fader Mackie/MCU controller, the channel buttons can switch the physical controls between as many as eight mapped channel strips inside one MIDI Command Studio preset.

Each channel can have its own fader, pan, mute, solo and record-style mappings. This allows one motorised fader to control several different Windows or application volume targets. For example, different MCU channels could be assigned to the main Windows output, a web browser, media player, communications application or other compatible Windows audio session.

When supported by the hardware and mapping, switching channels can also update the motorised fader position, LEDs and display information to match the currently selected target.

Use multi-fader MCU controllers for several applications at once

On a multi-fader MCU controller, each channel strip remains available on its own physical controls.

This makes it possible to keep several Windows or application volume controls accessible simultaneously, or to combine volume controls with shortcuts, macros and other mapped actions across multiple channel strips.

A larger MCU surface can therefore operate as a Windows mixer or application-control surface.

MCU motorised-fader, LED and display feedback

Compatible Mackie/MCU controllers can receive supported feedback from MIDI Command Studio.

Depending on the hardware, this can include motorised-fader movement, button LEDs, channel or preset information on displays, and other mapped control states.

MCU implementations vary between manufacturers and controller models, so the exact controls and feedback available depend on the hardware.

Select Mackie Control or MCU mode, not HUI

For MIDI Command Studio, select MCU, Mackie Control or Mackie Control Universal mode on the controller where one of those options is available.

Do not select HUI mode, which uses a different control protocol.

The method used to change operating mode varies between controller models. The X-Touch One volume control guide explains how MIDI and MCU/Mackie modes change the way the X-Touch One accesses several Windows or application volume targets.
