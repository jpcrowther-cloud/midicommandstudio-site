Use MIDI controls to run multi-step macros in Windows.

Combine shortcuts, waits, text, mouse actions, and launch steps into an ordered macro that starts from one button, pad, knob, or other mapped control.

Build practical action chains without scripting.

Shortcut sequences

Send several keyboard shortcuts in order from one mapping.

Waits and timing

Add delays so an application or earlier action has time to respond.

Text and mouse input

Combine typed text and mouse actions with shortcut steps.

Program and file launch

Open applications, files, folders, or Windows shortcuts as part of the sequence.

Favourite reuse

Save useful macros to favourites so they are easier to keep and reuse across setups.

Launch with arguments

Add optional command-line arguments when a macro launches an application.

Build and edit macros in the Macro Editor.

Add and arrange actions in the Macro Editor. No scripting is required.
