MIDI Command Studio features

Map buttons, pads, knobs, faders, encoders, and jog wheels to shortcuts, macros, Windows audio, app-specific actions, and controller feedback.

Features at a glance

  • MIDI Learn

    Learn buttons, pads, knobs, faders, encoders, jog wheels, and supported touch faders.

  • Keyboard shortcuts

    Capture your own shortcut or choose one from the built-in shortcut palette.

  • Application targeting

    Keep shortcuts global, limit them to a focused app, or bring the selected app forward before sending.

  • Multi-step macros

    Combine shortcuts, waits, mouse actions, text input, and program or file launches with optional arguments.

  • Windows audio

    Control system volume, individual application volume, and supported input volume and mute targets.

  • Per-device presets

    Create different layouts for each controller and switch or cycle through them from the hardware.

  • Controller feedback

    Use LED feedback, plus LCD labels and motorised-fader feedback on supported hardware.

  • MIDI Thru

    Pass unmapped MIDI messages to another application through a configured virtual MIDI port.

  • Audio sample playback

    Trigger and stop samples, choose playback behaviour, and control sample volume. Requires a licence.

  • Multiple active devices

    Use more than one MIDI device at the same time after activating a licence.

  • Automatic saving

    Preset mappings and device settings are saved automatically.

  • Standard MIDI and MCU

    Use ordinary MIDI controls or supported Mackie Control Universal hardware and feedback.

Connect devices, create mappings, and switch presets.

MIDI Command Studio listens to a connected MIDI controller and translates its controls into useful Windows actions. Learn a physical control, choose what it should do, and save it as part of a preset.
