Behringer X-Touch One / MIDI Command Studio

Use the Behringer X-Touch One as a Windows control surface

The Behringer X-Touch One can be used as a general-purpose Windows control surface. With MIDI Command Studio, its motorised fader, buttons, rotary encoder and transport controls can be mapped to Windows volume, individual application volume, keyboard shortcuts, macros, media controls and other Windows actions.

The controller can operate in standard MIDI or Mackie/MCU mode, giving you different ways to combine its controls, motorised fader, LCD and button LEDs with Windows applications.

Control Windows and application volume with the motorised fader

The X-Touch One's motorised fader can control the main Windows output or the volume of a selected application.

Because the fader is motorised, MIDI Command Studio can also move it to the current mapped volume when you change presets or switch between supported targets. This makes the X-Touch One particularly useful as a Windows volume controller rather than just a one-way MIDI fader.

The X-Touch One volume control guide explains how standard MIDI and MCU/Mackie operation can be used to move between several Windows or application volume targets.

Map X-Touch One buttons to shortcuts and macros

Buttons on the X-Touch One can be assigned to keyboard shortcuts, multi-step macros, media commands, application actions and MIDI Command Studio preset changes.

This makes it possible to use the controller with applications such as web browsers, media players, OBS and other Windows software, with the same controls performing different actions depending on the selected preset.

Use presets to give the X-Touch One different Windows layouts

MIDI Command Studio presets let the same X-Touch One controls perform different jobs for different applications or tasks.

X-Touch One LED, LCD and motorised-fader feedback

MIDI Command Studio supports several forms of X-Touch One feedback, depending on the selected mode and mappings.

Supported feedback can include button LEDs, preset or channel information on the LCD, and motorised-fader movement to reflect the current mapped volume or control state.
