Akai LPD8 MK2 / MIDI Command Studio

Use the Akai LPD8 MK2 as a Windows controller

The Akai LPD8 MK2 can be used for much more than controlling music software. With MIDI Command Studio, its eight pads and eight knobs can become physical controls for Windows volume, application volume, keyboard shortcuts, macros, media controls and other Windows actions.

The LPD8 MK2 is a class-compliant USB MIDI controller, so Windows normally recognises it without requiring a separate MIDI driver. Once it has been added to MIDI Command Studio, its pads and knobs can be learned directly and assigned to Windows controls.

Map the LPD8 MK2 pads to shortcuts and macros

The eight pads can send MIDI Note or Control Change (CC) messages. Either type can be mapped to keyboard shortcuts, multi-step macros, media commands, application actions or MIDI Command Studio preset changes.

This makes it possible to use the LPD8 MK2 as a compact shortcut controller for Windows applications.

Control Windows and application volume with the knobs

The eight rotary knobs send MIDI CC values and can be mapped to Windows system volume or individual application volume. For example, different knobs could control the main Windows output, a web browser, media player or another application that exposes a Windows audio session.

The knobs can also be used for controlling Windows input levels.

Use the four LPD8 MK2 Programs as additional control banks

The LPD8 MK2 can store four hardware Programs. Using the Akai LPD8 MK2 Program Editor, each Program can be given different MIDI note and CC assignments.

Giving the pads and knobs unique MIDI numbers in each Program lets the same physical controls perform different Windows actions when you switch Programs. These hardware Programs can also be combined with MIDI Command Studio presets to create additional layouts for different applications or workflows.

LPD8 MK2 pad colours and LED feedback

The LPD8 MK2's RGB pad colours are configured through the Akai Program Editor, so LED feedback isn't supported.
