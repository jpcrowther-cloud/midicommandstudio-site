Akai LPD8 MK2 Windows setup

Turn eight pads and eight knobs into a compact Windows control surface for shortcuts, macros, media commands, application actions, and volume control.

Quick setup Note & CC Programs Example layout

A small controller with several useful layers.

MIDI Command Studio lets you use the Akai LPD8 MK2 to control Windows system and application volume, trigger keyboard shortcuts and macros, send media commands, open programs, and run app-specific actions. The controller has eight pads and eight knobs, while its four stored hardware Programs can give those controls different MIDI assignments for different layouts.

The LPD8 MK2 is USB-powered and class-compliant, so Windows normally recognises it without a dedicated driver. Akai specifies eight velocity-sensitive RGB pads, eight 270-degree knobs, and four Programs that can be configured with its free editor software. See the official LPD8 MK2 product information.

Connect, learn, and test a first mapping.

Select Note or CC mode for the pad mappings you want to use. The knobs send CC messages in either mode.

  1. 01
    Connect

    Connect the LPD8 MK2 to the computer by USB.

  2. 02
    Add the device

    Open MIDI Command Studio, choose Add Device, and select the LPD8 MK2.

  3. 03
    Select a pad mode

    Press Note or CC on the controller.

  4. 04
    Learn a control

    Use the appropriate Learn button, then press a pad or turn a knob.

  5. 05
    Choose an action

    Select a shortcut, macro, media command, application action, or volume target.

  6. 06
    Test

    Save the mapping and test it from the controller.

Understand what the pads and knobs send.

The mode buttons change the messages sent by the pads, not the knobs.

Pad mode

Note mode

The pads send MIDI Note messages. These can be learned and assigned to shortcuts, macros, media commands, and other button actions.

Pad mode

CC mode

The pads send MIDI Control Change messages. These can be used for the same types of button actions or as another pad layer with different assignments.

Continuous control

Knobs

The eight knobs send CC values regardless of the selected pad mode, making them suitable for system, application, and input volume controls.

Program Change mode

The controller also has a Program Change pad mode, but it is not needed for normal MIDI Command Studio mappings. Note and CC are the relevant modes for learned pad actions.

Give the same physical controls four different MIDI layouts.

Hold the Program button and press the pad for the Program you want to use. To make each Program operate as a separate bank in MIDI Command Studio, assign different note and CC numbers in the Akai LPD8 MK2 Program Editor. If two Programs send the same MIDI number on the same channel, MIDI Command Studio will treat them as the same control.

With unique assignments, the four Programs can provide 32 distinct pad assignments and 32 distinct knob assignments while keeping the physical controller small. Advanced layouts can also configure the Note and CC pad layers separately, although using one main pad mode per Program is easier to remember.

Inside the controller

Akai Program

A bank of MIDI numbers stored inside the LPD8 MK2.

Inside the application

MCS preset

The Windows actions assigned to MIDI controls. Use hardware Programs within one app preset, or combine both systems for more layouts.

Akai documents how to edit, store, and select the four Programs in its LPD8 MK2 editor guide.

Use pads for direct commands or complete sequences.

Shortcut

Trigger keyboard shortcuts

Learn a pad in Note or CC mode, choose a keyboard shortcut, and optionally target a particular Windows application. Pads can perform commands such as Save, Undo, Copy, Paste, Play/Pause, browser tabs, or software-specific shortcuts.

App targeting can reserve a shortcut for one program, while the LPD8 MK2 Programs can separate general Windows, editing, browser, or media layouts.

Macro

Run multi-step actions

A MIDI Command Studio macro can combine shortcuts, waits, text input, mouse actions, and program or file launch steps.

  • Open an application and send its first shortcut.
  • Run a repeated editing sequence with timed steps.
  • Enter frequently used text or commands.
  • Launch a program, file, folder, or Windows shortcut.

Pad lighting is controlled by the LPD8 MK2.

LED feedback is not supported

The LPD8 MK2 controls its own pad lighting and does not support LED feedback from MIDI Command Studio. Pad colours and press behaviour are configured in Akai's Program Editor and stored with each hardware Program.

See Akai's LPD8 MK2 FAQ for its description of pad modes, colours, Programs, and class-compliant operation.
