  3. Windows volume

Control Windows and app volume with a MIDI controller.

Map a knob, fader, or supported encoder to the main Windows volume or the volume of a selected application.

Control the whole system or one application.

Master output

System volume

Assign a physical control to the main Windows output level when one control should affect the system as a whole.

Selected audio session

Application volume

Choose App Target Volume when the physical control should follow the Windows audio session created by a particular running application.

Microphone and line-in endpoints use the separate Windows input-volume and mute workflow.

Use a fader, knob, or supported encoder.

Fader

Linear volume control

Move a fader to set the volume level directly.

Knob

Rotary volume control

Use an absolute rotary control for system or application volume.

Encoder

Relative volume control

Use a supported encoder to raise or lower the selected volume target.

Map a MIDI control to system or application volume.

  1. 01
    Add the device

    Add your MIDI device in MIDI Command Studio.

  2. 02
    Learn the control

    Click Learn Fader/Knob and move the control you want to use.

  3. 03
    Choose volume mapping

    Select a volume mapping type in the editor.

  4. 04
    Select the target

    Choose System for master volume or App Target for a specific application.

  5. 05
    Save and test

    Save the mapping, then move the physical control.

Application volume depends on an active Windows audio session.

For App Target Volume

The target application must be running and producing audio so Windows creates the audio session that MIDI Command Studio can target.
