Behringer X-Touch One / Windows volume control

Control Windows volume with a Behringer X-Touch One.

MIDI Command Studio lets the X-Touch One's motorised fader control the main Windows output or the volume of a selected application. It works in standard MIDI mode and Mackie Control (MCU/MC Std) mode, with each mode providing a different way to work with additional volume targets.

MIDI mode makes the fader and buttons ordinary MIDI controls that can be mapped freely. It suits custom workflows built around presets: one preset might control Windows volume, another Spotify, another a browser, and another VLC. Changing presets changes what the same fader controls, while supported feedback can move the fader to the selected volume and show the preset name on the LCD.

MCU/Mackie mode makes the X-Touch One behave like a compact mixer. Its CH1–CH8 buttons select eight channel strips inside one MIDI Command Studio preset. The fader, pan encoder, Mute, Solo, and Rec controls follow the selected strip, providing up to eight sets of controls without changing presets. The channel buttons are reserved for strip selection, and the Master button selects the master channel. With feedback enabled, the fader, LCD, and LEDs update as the selected channel changes.

Choose MIDI mode for freely assignable controls and separate application or task presets. Choose MCU/Mackie mode for mixer-style access to several volume targets within one preset.
