Use a MIDI controller with OBS on Windows.

Map MIDI controls to keyboard shortcuts configured in OBS, and use the same controller for Windows input volume, mute, macros, and preset switching.

Map MIDI controls to OBS hotkeys and Windows audio controls.

OBS hotkeys

Map buttons or pads to the keyboard shortcuts already configured in OBS.

Windows input

Use a fader and button for a Windows microphone or input endpoint that OBS receives.

Macros and presets

Add multi-step actions, create layouts for different tasks, and switch presets from the controller.

How it works

MIDI Command Studio controls OBS through keyboard shortcuts configured in OBS. It can also control Windows audio endpoints that OBS uses; it does not connect to OBS through a plugin or direct integration.

Set up an OBS control preset.

  1. 01
    Configure the hotkey in OBS

    Choose the OBS action and note the keyboard shortcut assigned to it.

  2. 02
    Learn a MIDI control

    Add the controller in MIDI Command Studio, learn the button or pad, and map that shortcut.

  3. 03
    Add audio controls if relevant

    Map a Windows input fader and mute button, or app/system output controls for the wider workflow.

  4. 04
    Save a clear preset

    Name the preset and mapping descriptions so the hardware role remains easy to recognise.

Control a Windows input before it reaches OBS.

If OBS uses a Windows microphone or other Windows input endpoint, a MIDI fader can control its input level and a button can mute it.

Open the input volume and mute workflow
Important boundary

This does not change audio-interface preamp gain, direct monitoring, or hardware monitor mixes. ASIO, exclusive-mode, or vendor-specific paths can bypass Windows input controls.
