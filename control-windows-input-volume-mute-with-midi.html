  3. Input volume & mute

Control Windows input volume and mute with a MIDI controller.

Map a fader or knob to a Windows microphone or other input, then assign a button to mute it.

Input volume is separate from Windows and app volume.

Input volume & mute

Control the default Windows input, or choose a specific microphone, line-in, or other input.

Output & app volume

Control the main Windows output or the volume of a selected application.

View Windows and app volume

Map MIDI controls to Windows input volume and mute.

  1. 01
    Add the device

    Add and enable your MIDI device in MIDI Command Studio.

  2. 02
    Learn a level control

    Click Learn Fader/Knob and move the control you want to use.

  3. 03
    Choose the default input

    In the mapping editor, set the control to Volume - Input (Default).

  4. 04
    Optional: expose specific inputs

    In Advanced settings, enable the option to show specific Windows input devices so the controls list can display all Windows inputs.

  5. 05
    Verify level

    Save the mapping and move the control to confirm that the Windows input level changes.

  6. 06
    Add mute

    Choose one of the mute methods below, then save and test mute and unmute.

Use a paired or standalone mute control.

Recommended with input fader

Paired mute

In the same fader mapping, enable Add mute control, choose Learn, and press the button to pair with that input.

Independent button or pad

Standalone mute

Learn the button, open its mapping editor, select Use as mute control..., and choose the input target in the mute dialog.

MIDI Command Studio controls the Windows input level, not hardware gain.

This mapping does not control hardware preamp gain, audio-interface direct monitoring, or hardware monitor mixes. Some ASIO, exclusive-mode, or vendor-specific paths can bypass Windows input controls, so behaviour depends on how the source is routed.
