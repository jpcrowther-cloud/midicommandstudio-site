Send keyboard shortcuts from a MIDI controller.

Map buttons, pads, and other suitable MIDI controls to keyboard shortcuts for Windows and individual applications.

Use MIDI buttons and pads for keyboard shortcuts.

Buttons & pads

Assign common application or Windows shortcuts to dedicated physical controls.

Shortcut Palette

Select an entry from the built-in shortcut lists or capture your own shortcut combination.

Preset switching

Create presets for different apps or workflows, then switch between them directly from your controller.

Map a keyboard shortcut to a MIDI control.

  1. 01
    Add the device

    Open MIDI Command Studio and add your device in the Devices panel.

  2. 02
    Learn a control

    Click the appropriate Learn button and move or press the control. The editor opens automatically.

  3. 03
    Choose the shortcut

    Click a shortcut field and choose an entry from the Shortcut Palette or capture your own shortcut.

  4. 04
    Target an app if needed

    Set App Targeting when the mapping should be associated with a particular application.

  5. 05
    Save and test

    Save the mapping, then operate the physical control.

Choose how the shortcut is sent.

Global

Send shortcuts to whichever application currently has focus.

App targeting

Send shortcuts to specific applications rather than sending every mapping globally.

A shortcut performs one command. A macro can combine shortcuts, waits, text, mouse actions, and launch steps into a sequence.
